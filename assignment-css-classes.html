Before you start

What you should already know

Skim this first. It covers the session and your research. Come back to it whenever a task feels unclear.

Classes

  • A class is a reusable label. In HTML: class="box". In CSS: .box { }.
  • One class can go on many elements. One element can have many classes: class="box box-one".
  • Shared look goes in .box. The differences go in .box-one.
  • An id like #home is unique on the page. Use it for links, and use classes for styling.
Variables, defined once and used anywhere 
:root {
  --accent: #ff5b36;
  --max-width: 1280px;
}
.btn-primary {
  background-color: var(--accent);
}
UnitRelative toUse it for
pxNothing. A fixed size.Thin borders, shadows.
remThe font size of the root (html), usually 16px.Font sizes, spacing, gaps. They scale with the user's browser settings.
emThe font size of the element itself. For font-size itself, the parent's.Padding on buttons, so it grows with the button's text.

em compounds. A child at 1.2em inside a parent at 1.2em is 1.44 times the base size. rem does not compound.

displayBehaviour
blockNew line, full width. Width and height work.
inlineStays in the line of text. Width and height are ignored.
inline-blockStays in the line. Width, height and vertical padding work.
flexChildren sit in a row. Use gap, justify-content, align-items.
noneRemoved from the page.
positionBehaviour
staticDefault. Normal flow. top and left do nothing.
relativeStays in flow, can be nudged. Anchor for absolute children.
absoluteLeaves the flow. Placed against the nearest positioned parent.
fixedLeaves the flow. Placed against the window. Stays while scrolling.
stickyScrolls normally, then sticks at an offset such as top: 5rem.

z-index decides which positioned element sits on top. It only works on elements that are positioned.

In writing

Questions to answer

Answer each in two or three sentences, in your own words. Save them in a file called answers.md in your project folder.

  1. When do you choose rem over em, and em over rem? Give one example of each from your page.
  2. Why can nesting em values make text too large, and how does rem avoid it?
  3. What is the difference between display: none and hiding something with opacity: 0?
  4. Why did your badge need its parent to have position: relative?
  5. Why does a fixed header need space reserved below it?
  6. When would you give an element two classes instead of one?

If something looks wrong

  • Nothing changes: check that css/styles.css is saved and the path in the link tag matches.
  • A class does nothing: check the dot in CSS (.btn) and the missing dot in HTML (class="btn").
  • The badge floats off the photo: the parent is missing position: relative.
  • The hero hides under the header: the header is fixed, so add padding to #home.
